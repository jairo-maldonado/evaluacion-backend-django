# Evaluación Sumativa 1 - Programación Backend (Caso 2: Control de Venta Básico)

## Instrucciones de ejecución:
1. Clonar el repositorio.
2. Crear y activar el entorno virtual: `python -m venv venv` y `venv\Scripts\activate` (Windows).
3. Instalar dependencias: `pip install -r requirements.txt`
4. Ejecutar migraciones: `python manage.py makemigrations` y `python manage.py migrate`
5. Iniciar el servidor: `python manage.py runserver`
